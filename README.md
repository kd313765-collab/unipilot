# UniPilot 🎓

UniPilot is a simple and smart college assistant web application designed to help students manage daily academic tasks efficiently.

## 🚀 Features

- Add and manage daily tasks (subject + date)
- View today's tasks in a clean list
- Simple and user-friendly interface
- Financial tip section for daily awareness
- Badge display system for motivation

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 📂 Project Structure

- index.html – Main structure of the app  
- style.css – Styling and layout  
- script.js – Functionality and logic  

## 💡 How It Works

- User enters subject name and date
- Task gets added to the list
- Tasks are displayed under "Today's Tasks"
- Additional sections provide tips and badge display

## 📌 Future Improvements

- Add database integration (store tasks permanently)
- User login system
- Reminder/notification feature
- Better UI design
